# Filament Profiler

Erzeugt Filamentprofile für **OrcaSlicer, Snapmaker Orca, Bambu Studio, PrusaSlicer/SuperSlicer und Cura** aus Hersteller- und Slicer-Daten – jeder Wert mit Quelle.

**Website:** https://kammberler435.github.io/Filament-Profiler/ (Daten werden täglich automatisch aktualisiert)

Ausführliche Anleitung (Desktop-App, Website, Datenquellen): [LIESMICH.md](LIESMICH.md)
